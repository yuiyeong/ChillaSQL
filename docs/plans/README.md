# 마일스톤 계획

마일스톤마다 시작할 때 계획 파일 하나를 쓴다. 파일 이름은 `M<n>-<name>.md` (예: `M0-setup.md`).

계획 파일 형식:

- 맨 위에 목표, 구조, 참고할 기획서 장
- [마일스톤](../milestones.md)의 "먼저 확인할 것"을 첫 task로 둔다
- task마다 만들거나 고칠 파일, 다른 task와 주고받는 interface, 체크박스 step(test 작성 → 실패 확인 → 구현 → 통과 확인 → commit)
- task를 끝내면 체크박스를 체크한다. 마일스톤 단위 상태는 [진행상황](../progress.md)에 쓴다
